# Projekt: colliding-circles.c

## Voraussetzungen
-   Raylib muss installiert sein
-   gcc compiler 

## Installation von raylib (Ubuntu)
-   sudo apt install libraylib-dev

## Kompilieren
-   gcc -colliding-circles.c -o main -lraylib

## Ausführen
-   ./main

## Build 
Dieses Projekt kann auch einfach mit dem Makefile kompiliert werden

```bash 
make
